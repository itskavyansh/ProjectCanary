# Data Dictionary and Schema Conventions

> [!CAUTION]
> **SYNTHETIC SIMULATION NOTICE:**
> All datasets, timelines, telemetry, and features described below are **SYNTHETIC / SIMULATION**. ProjectCanary-Sim is an algorithmic benchmarking harness, not a geomechanical simulation or real field ground truth.

---

## 1. Coordinate Frames and Geometry

Right-handed Cartesian local frame in meters: $x$ east, $y$ north, $z$ up. Origin $(0, 0)$ is fixed at `NODE_01`.

| Node ID | $(x, y)$ Coordinates (m) | Role |
|---|---|---|
| `NODE_01` | $(0, 0)$ | Corner node (IMU + Piezo) |
| `NODE_02` | $(20, 0)$ | Corner node (IMU + Piezo) |
| `NODE_03` | $(20, 20)$ | Corner node (IMU + Piezo) |
| `NODE_04` | $(0, 20)$ | Corner node (IMU + Piezo) |
| `HUB` | $(10, 10)$ | Central LiDAR range scanner (scans 4 corner nodes) |

- **Network Center:** $(10, 10)\text{ m}$
- **Network Radius ($R_{\text{network}}$):** Center-to-corner distance $= 10\sqrt{2} \approx 14.14\text{ m}$.
- Configured basin radii are expressed as multiples of $R_{\text{network}}$.

---

## 2. Sensor Mounting and Orientation

- **Body to World Tilt Transformation:**
  World slope vectors $(\partial w/\partial x, \partial w/\partial y)$ are rotated into node-local sensor frames using each node's effective mounting yaw $\psi$:
  $$\begin{aligned}
    g_{x, \text{local}} &= \cos\psi \cdot g_x + \sin\psi \cdot g_y \\
    g_{y, \text{local}} &= -\sin\psi \cdot g_x + \cos\psi \cdot g_y \\
    \text{tilt}_{x, \text{deg}} &= +\arctan(g_{y, \text{local}}) \quad (\text{about sensor } +x) \\
    \text{tilt}_{y, \text{deg}} &= -\arctan(g_{x, \text{local}}) \quad (\text{about sensor } +y)
  \end{aligned}$$
- **Field Installation Compass Yaw Requirement:**
  Feature extraction transforms local tilts back into the world frame using nominal installation yaw $\psi_{\text{nom}}$. As documented in `docs/report_eval_v3_yaw.md`, installers must record compass yaw within $\sigma_{\text{yaw}} \le 10^\circ$, and avoid single-node gross blunders $\ge 45^\circ$.

## 3. File Formats and Schemas

### 3.1 State Timeline (`state_timeline.csv`)
*Ground-truth physical state generated by the settlement engine. Schema is FROZEN (`docs/schema_v1.md`). Never contains sensor noise, faults, or telemetry labels.*

| Column | Type | Units | Description |
|---|---|---|---|
| `time_s` | float | s | Simulation timestamp |
| `node_id` | string | - | Node identifier (`NODE_01`..`NODE_04`, `HUB`) |
| `true_x_m` | float | m | Undisplaced nominal X position |
| `true_y_m` | float | m | Undisplaced nominal Y position |
| `true_z_m` | float | m | Undisplaced nominal Z elevation |
| `true_disp_x_m` | float | m | Ground displacement along X axis |
| `true_disp_y_m` | float | m | Ground displacement along Y axis |
| `true_disp_z_m` | float | m | Vertical subsidence displacement $w(x, y, t)$ |
| `true_tilt_x_deg` | float | deg | True physical surface tilt about body X (including mounting offset) |
| `true_tilt_y_deg` | float | deg | True physical surface tilt about body Y (including mounting offset) |
| `active_class` | string | - | Physical ground condition (`normal`, `gradual`, `rapid`) |

### 3.2 Telemetry (`telemetry.csv`)
*Corrupted observable signals output by the sensor layer (`canary_sim/sensors.py`).*

| Column | Type | Units | Description |
|---|---|---|---|
| `time_s` | float | s | Telemetry sample timestamp (1.0 s nominal sample interval) |
| `node_id` | string | - | Node identifier (`NODE_01`..`NODE_04`) |
| `tilt_x_deg` | float | deg | Measured IMU tilt X (with bias, drift, white noise, faults) |
| `tilt_y_deg` | float | deg | Measured IMU tilt Y (with bias, drift, white noise, faults) |
| `piezo_peak` | float | V / arb | Maximum piezo voltage amplitude over window |
| `piezo_rms` | float | V / arb | RMS piezo vibration energy |
| `piezo_peak_to_peak` | float | V / arb | Peak-to-peak piezo voltage span |
| `hub_range_m` | float | m | Measured distance from LiDAR hub (updated once per sweep) |
| `packet_dropped` | int | bool (0/1) | Whether packet was dropped in transmission |
| `latency_ms` | float | ms | Network transmission latency |

### 3.3 Window Labels (`window_labels.csv`)
*Window-level classification ground truth derived according to `docs/label_policy.md`.*

| Column | Type | Description |
|---|---|---|
| `simulation_id` | string | Simulation run identifier (e.g. `sim_gradual_20260001`) |
| `window_idx` | int | Sequential window index (0, 1, 2, ...) |
| `t_start` | float | Window start time in seconds |
| `t_end` | float | Window end time in seconds ($t_{\text{start}} + 5.0\text{ s}$) |
| `label` | string | Primary class (`normal`, `gradual`, `rapid`, `abnormal_vibration`, `sensor_fault`, `comm_fault`, `transition`) |
| `label_set` | string | Pipe-separated list of all classes with overlap $\ge 50\%$ |
| `partial_set` | string | Pipe-separated list of classes with overlap $0 < f < 50\%$ |
| `t_rel_event_start_s` | float | Offset from window center to event onset (NaN for normal runs) |
| `overlap_{class}` | float | Exact overlap fraction $[0.0, 1.0]$ for each condition class |
| `split` | string | Dataset partition (`train`, `val`, `test`, `shifted_test`, `stress`, `broad_basin`) |

### 3.4 Window Features (`window_features.csv` - v3 Feature Set)
*Model feature table computed by `canary_sim/features.py`. Diagnostic columns (`diag_*`) are excluded from model training.*

| Column Group | Columns | Description |
|---|---|---|
| Identifiers & Labels | `simulation_id`, `window_idx`, `t_start`, `t_end`, `label`, `label_set`, `partial_set`, `t_rel_event_start_s`, `split` | Window metadata and labels |
| Per-Node Tilt Stats | `{node}_mean`, `{node}_std`, `{node}_min`, `{node}_max`, `{node}_rate_deg_s`, `{node}_delta_deg`, `{node}_missing_frac` | IMU tilt magnitude summary statistics for `NODE_01`..`NODE_04` |
| Network Tilt Aggregates | `tilt_max_mean`, `tilt_net_mean`, `tilt_net_std`, `tilt_net_max_rate`, `tilt_net_coherence` | Multi-node consensus and spread metrics |
| World-Frame & Direction (v3) | `tilt_world_pitch_deg`, `tilt_world_roll_deg`, `tilt_world_azimuth_deg`, `radial_alignment_deg`, `radial_fit_residual_deg`, `trailing_coherence_mean` | World-frame rotated tilt, fitted radial convergence alignment, and causal history coherence |
| Piezo Vibration | `{node}_piezo_peak_max`, `{node}_piezo_rms_mean`, `{node}_piezo_p2p_max`, `{node}_piezo_impulse_count`, `piezo_impulse_total`, `piezo_nodes_with_impulse`, `piezo_max_peak`, `piezo_max_rms` | Vibration intensity and multi-node impulse spread |
| LiDAR Hub | `{node}_lidar_range_m`, `{node}_lidar_staleness_s`, `{node}_lidar_residual_m`, `hub_staleness_max_s`, `hub_residual_abs_max_m`, `hub_range_delta_max_m` | Distance readings, age of reading, and geometric residual |
| Network & Comm | `{node}_packet_loss_frac`, `{node}_latency_p95_ms`, `comm_missing_frac_net`, `comm_max_burst_len`, `comm_nodes_unavailable`, `comm_latency_mean_s`, `comm_latency_max_s` | Packet loss ratios, burst lengths, and latency percentiles |
| Diagnostic Columns | `diag_*` | Internal engineering checks; **strictly excluded** from ML models |

### 3.5 Run Manifest (`manifest.csv`)
*Index of all runs in a generated dataset partition.*

| Column | Type | Description |
|---|---|---|
| `simulation_id` | string | Unique run identifier |
| `split` | string | Target split (`train`, `val`, `test`, `shifted_test`, `stress`, `broad_basin`) |
| `run_class` | string | Headline condition class |
| `conditions` | string | Pipe-separated active conditions |
| `fault_types` | string | Injected fault types (empty for normal/clean runs) |
| `seed` | int | Master PRNG seed for the run |
| `duration_s` | float | Simulated duration in seconds (240.0 s nominal) |
| `n_windows` | int | Total number of 5 s windows extracted |
| `peak_tilt_deg` | float | Peak surface tilt across the network area |
| `snr_vs_imu_noise` | float | Ratio of peak tilt signal to IMU noise floor |
| `compression_factor` | float | Ratio of physical real-world duration to simulated duration |
| `parameters_json` | json | JSON dump of ground settlement parameters |
| `faults_json` | json | JSON dump of sensor/comm fault parameters |
| `events_json` | json | JSON dump of vibration event parameters |

### 3.6 Dataset Metadata (`metadata.json`)
*Cryptographic provenance and environment manifest written by `canary_sim/versioning.py`.*

| Key | Type | Description |
|---|---|---|
| `created_utc` | string (ISO-8601) | UTC timestamp of dataset creation |
| `synthetic` | bool (`true`) | Explicit marker confirming synthetic origin |
| `git` | object | Git state: `commit` SHA, `dirty` flag, and `dirty_file_count` |
| `libraries` | object | Exact pinned library versions (`numpy`, `pandas`, `scikit-learn`, etc.) |
| `configs` | object | Embedded text content and SHA-256 digests of all configuration files |
| `files` | object | Dictionary mapping relative file paths to SHA-256 hashes and file byte sizes |
| `extra` | object | Run parameters (e.g. `quick` flag, effective dataset overrides) |

### 3.7 Evaluation Metrics Table (`headline_metrics.csv`)
*Comprehensive benchmarking outputs computed by `canary_sim/evaluate.py`.*

| Column | Description |
|---|---|
| `split` | Evaluated dataset split (`test`, `shifted_test`, `stress`, `broad_basin`) |
| `version` | Pipeline version (e.g. `v3 (new features)`) |
| `regime` | Alarm tuning regime (`episode_fa<=1 (k=3,m=3)` or `strict_window_fa<=1`) |
| `model` | Evaluated classifier (`threshold_rule`, `logistic_regression`, `random_forest`) |
| `k` | Persistence alarm confirmation window count |
| `m` | Persistence alarm clearance window count |
| `window_macro_f1` | Window-level Macro-averaged F1 score |
| `window_macro_f1_ci_lo/hi` | 95% confidence intervals from run-level bootstrap |
| `alarm_macro_f1` | Alarm-level Macro-averaged F1 score |
| `alarm_macro_f1_ci_lo/hi` | 95% confidence intervals from run-level bootstrap |
| `fa_episodes_per_normal_run` | Mean count of false alarm episodes per normal run |
| `fa_windows_per_normal_run` | Mean count of false alarm windows per normal run |
| `alarm_exact_detect_rate` | Fraction of event runs where the exact true event class was alarmed |
| `alarm_exact_detect_ci_lo/hi`| 95% confidence intervals for exact detection rate |
| `mean_delay_exact_s` | Mean detection delay from event onset to first confirmed alarm (s) |
